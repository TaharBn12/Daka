# دكا — Daka

تطبيق Flutter عربي RTL لتنظيم ومتابعة نسبة الربح الشهرية في التداول.

## المزايا
- لوحة رئيسية بملخص الربح والخسارة، رأس المال، الهدف، شريط التقدم، والمبلغ المتبقي أو التجاوز.
- تسجيل حالة كل شهر بعلامة نجاح أو عدم تحقيق الهدف.
- إدخال رأس المال ونسبة الهدف.
- إحصائيات شهرية مع متوسط الربح وعدد الأشهر الناجحة.
- حاسبة مركبة لمدة سنة إلى خمس سنوات تعرض رأس المال المتوقع والربح الشهري المطلوب.

## التشغيل
```bash
flutter pub get
flutter run
# أو للويب
flutter run -d chrome
```

> البيانات حالياً محلية داخل التطبيق، والخطوة التالية للإنتاج هي ربطها بقاعدة بيانات وتفعيل تسجيل الدخول.
